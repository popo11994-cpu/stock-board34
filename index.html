GitHub Gist 跨裝置雲端同步

任一裝置修改持股後自動上傳，其他裝置開啟即同步

  1. 前往 GitHub 產生 Gist Token（已預設僅勾選 gist 權限）。
  2. 第一台裝置只需貼上 Token，Gist ID 留空按「儲存並建立雲端同步」，系統會自動建立私人 Gist 並產生一組 ID。
  3. 在第二台裝置（例如手機）貼上同一組 Token 與 Gist ID 即可雙向同步。

設定即時報價 API

Alpaca 免費方案支援美股盤前（Pre-market）與盤後（After-hours）即時報價，適合在台灣晚上直接追蹤美股盤前漲跌，且單次即可批次更新所有持股。

  1. 前往 app.alpaca.markets 免費註冊。
  2. 在右側 Paper Trading 面板點選 API Keys → Generate。
  3. 複製 API Key ID 與 Secret Key 貼到下方。

Finnhub 免費方案每分鐘支援 60 次查詢，提供美股正規盤中即時報價與即時公司新聞（不含盤前／盤後）。

  1. 前往 finnhub.io/register 免費註冊。
  2. 登入後在 Dashboard 複製你的 API Key 貼到下方。

富果 Fugle 行情 API 提供台股與台股 ETF（如 0050、00631L）盤中即時現價與漲跌幅，基本用戶免費方案每分鐘支援 60 次查詢（可與美股 API 同時運作）。

  1. 前往 富果 Fugle 開發者平台 申請免費行情 API Key。
  2. 複製你的 X-API-KEY 貼到下方儲存，台股盤中即會同步即時跳動。
